# Customer Shopping Analysis

A Python-based analysis of customer shopping trends using Pandas, NumPy, Matplotlib, and Seaborn.

## Objective

The objective of this project is to analyze customer shopping data and identify patterns in purchasing behavior, sales performance, and customer preferences using Python.

## Dataset Description

The dataset used for this project is the Customer Shopping Trends dataset obtained from Kaggle.

The dataset contains 3,900 customer records and 18 attributes related to customer shopping behavior. It includes information about customer demographics, products purchased, purchase amount, location, season, review ratings, subscription status, payment methods, shipping type, discounts, previous purchases, and purchase frequency.

## Technologies and Libraries Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook
- VS Code

## Analysis Performed

The project analyzes:

- Customer demographics
- Product categories
- Most purchased items
- Sales by location
- Payment methods
- Subscription status
- Discount and promotional code usage
- Purchase frequency
- Customer review ratings
- Purchase amount distribution

## Key Findings

1. Male customers made more purchases than female customers.
2. Clothing generated the highest total sales among the categories.
3. Blouse, Jewelry, and Pants were among the most frequently purchased items.
4. Sales were distributed fairly evenly across payment methods.
5. Purchase frequency categories showed relatively similar total sales.
6. Footwear had the highest average review rating among the categories.
7. Purchase amounts ranged from $20 to $100.

## Conclusion

The Customer Shopping Analysis provides useful insights into customer purchasing patterns and sales performance. The analysis helps identify trends in customer preferences, product categories, purchasing frequency, payment methods, and review ratings.

The project demonstrates the use of Python and data analysis libraries to explore, analyze, and visualize real-world customer shopping data.
